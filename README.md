# AlienGame_Project_Python
# 👾 Alien Invasion Game

## About the Project
Alien Invasion is a Python-based arcade game in which the player controls a spaceship to defend against waves of invading aliens. The player shoots bullets to destroy aliens, earns points, and tries to achieve the highest score while protecting the ship.

## Features
- Spaceship movement and controls
- Alien invasion and enemy movement
- Shooting bullets to destroy aliens
- Score tracking and scoreboard
- Game settings and difficulty management
- Interactive game buttons

## Technologies Used
- Python
- Pygame

## How to Run

1. Install Python on your computer.
2. Install Pygame:

   ```bash
   pip install pygame
   ```

3. Clone or download this repository.
4. Open the project folder.
5. Run the following command:

   ```bash
   python alien_invasion.py
   ```

6. Enjoy the game!
